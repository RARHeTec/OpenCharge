# ADR-0001: 金额使用 int64 定点数（scale=4）

- 状态：Accepted
- 日期：2026-11-24

## 背景

电费、服务费、余额混用浮点会导致精度误差；BigDecimal 在 Go 无标准库支持；"毫"（0.001 元）无法表示 4 位小数电价。

## 决策

全链路统一 `int64` 定点数，1 单位 = 0.0001 元（scale=4）。中间计算保留 4 位，结算时 half-up 取到分。JSON 用字符串传输。

## 后果

- 优点：零精度误差、无第三方依赖、跨语言传输安全
- 代价：所有金额入口必须调用 `money.ParseYuan`，禁止直接构造 float
