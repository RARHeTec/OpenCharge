# 云快充 V1.6 服务端

依据《云快充平台协议 V1.6 新》实现的**真实 TCP 服务端**。桩端作为客户端主动连接，符合协议标准接入方式。

## 帧格式（协议 §3.1）

```
68 | 长度(1) | 序列号(2,小端) | 加密标志(1) | 帧类型(1) | 消息体(N) | CRC(2,低字节在前)
```

- CRC：标准 CRC-16/Modbus（init 0xFFFF，poly 0xA001），覆盖「序列号→消息体」
- 长度：序列号+加密+类型+消息体 的字节数，上限 200
- 序列号：从 0 递增；应答帧与请求帧序列号保持一致

## 已实现帧类型

| 类型码 | 方向 | 说明 | 服务端行为 |
|---|---|---|---|
| 0x01 | 上行 | 登录认证 | 白名单放行任意桩，回 0x02 成功 |
| 0x03 | 上行 | 心跳 | 回 0x04 |
| 0x05 | 上行 | 计费模型验证 | 回 0x06 一致 |
| 0x13 | 上行 | 实时遥测 | 解析并内存聚合，走快通道 |
| 0x31 | 上行 | 桩主动申请启动 | 记录事件 |
| 0x33/0x35 | 上行 | 启机/停机回复 | 记录事件 |
| 0x3B | 上行 | 交易记录 | 解析四个时段电价/电量/金额，回 0x40 确认 |
| 0x34/0x36 | 下行 | 远程启机/停机 | `Server.RemoteStart/RemoteStop` 主动下发 |

## 启动服务端

```bash
cd charging-iot-gateway
CGO_ENABLED=0 go build -o gateway ./cmd/gateway
./gateway -addr :8768        # 协议默认端口 8768
```

## 用内置模拟器联调

```bash
CGO_ENABLED=0 go build -o sim ./device-simulator/ykc
./sim -addr 127.0.0.1:8768 -device 55031412782305 -gun 1
```

模拟器会依次发送：登录 → 心跳 → 遥测(0.5 kWh) → 交易记录(0.3 元)，并打印每帧 Hex。服务端打印双向原始报文、TraceId 与解析结果。

## 测试

```bash
CGO_ENABLED=0 go test ./adapter-yunkuaichong/... ./integration/...
```

包含：CRC golden 向量、编解码往返、TCP 粘包拆分、完整登录→心跳→遥测→交易流程、快慢通道分流、枪头锁防重复启动。

## 注意事项

- 本环境需用 `CGO_ENABLED=0`，否则 dyld 拒绝加载生成的二进制（missing LC_UUID），属环境问题非代码问题。
- 协议文档 PDF 中样例报文的 CRC 字段为示意占位值（多个不同帧重复出现 `6890`、`C1A9`），不能作为校验基准；CRC 实现以附录 13.2 的标准 Modbus 算法为准，并用独立 golden 向量验证。
- 交易记录报文体为 158 字节（不含帧头/长度/CRC）。
